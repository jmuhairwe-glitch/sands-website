# SANDS Website

One-page Next.js website for SANDS FISH FARM (U) LIMITED.

## Deploy on Vercel
1. Upload this folder to a new GitHub repository named `sands-website`.
2. Import the repository into Vercel.
3. Deploy.
4. Assign `sands.co.ug` and `www.sands.co.ug` to the new Vercel project.

Important: keep the existing Resend email DNS records intact.
